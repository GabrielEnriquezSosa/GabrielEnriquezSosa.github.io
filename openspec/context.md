# Project Context

## Stack
- Vanilla HTML, CSS, JavaScript

## Architecture
- Multi-page static site
- Assets in `/assets`
- Stylesheets in `/css`
- Scripts in `/js`
- Additional pages in `/pages`
- Entrypoint at `index.html`

## Conventions
- Spanish language for content and context.
- Native DOM manipulation. No frontend framework used.

## Testing
- No test runner or testing framework present.
